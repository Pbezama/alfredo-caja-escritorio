# Alfredo Caja para escritorio

Shell de escritorio (Tauri v2) de [Alfredo](https://asistentealfredo.cl), de CreceTec SpA: envuelve la
web staff del local con impresión directa en la térmica, bandeja del sistema, alarma de pedidos,
anti-suspensión, actualización automática firmada y soporte remoto.

Espejo de `apps/desktop` del repositorio privado del SaaS: los cambios se hacen allá. Este repositorio
compila el instalador de Windows (GitHub Actions) y publica las versiones en Releases.

Descarga: <https://asistentealfredo.cl/descargar/windows>
